# تقویم | Taghvim

![Version](https://img.shields.io/badge/version-1.1.0-282549)

برنامه‌ریزی هفتگی و مدیریت امتحان‌ها — سریع، واکنش‌گرا، راست‌به‌چپ و فارسی.

## قابلیت‌ها

- نمای هفتگی بهینه برای دسکتاپ و انتخاب سریع روز در موبایل
- ثبت ساعت، رنگ دلخواه و **توضیحات جداگانه برای هر برنامه و امتحان**
- **زیرتسک برای هر برنامه** با شماره‌های ایموجی خودکار، امکان انتخاب استیکر دلخواه برای هر زیرتسک، تیک جداگانه و نوار پیشرفت هفتگی که هر هفته خودکار صفر می‌شود؛ توضیحات و زیرتسک‌ها فقط وقتی وجود داشته باشند نمایش داده می‌شوند
- **استیکر دلخواه برای هر برنامه** که به‌شکل بزرگ کنار عنوان برنامه نمایش داده می‌شود
- **جابه‌جایی با کشیدن و رها کردن (Drag & Drop):** هر برنامه یک دستگیره‌ی کشیدن دارد؛ با آن برنامه را درون روز خودش بالا و پایین ببر یا به روز دیگری از هفته منتقل کن. روی موبایل می‌توانی کارت را روی دکمه‌ی روز موردنظر در بالای صفحه رها کنی. برنامه‌های انجام‌شده همیشه ته فهرست می‌مانند و جابه‌جایی در حالت جست‌وجو غیرفعال است
- **جابه‌جایی با دکمه** (گزینه‌های «بالا بردن» و «پایین بردن» در منوی ⋯) برای کیبورد و صفحه‌خوان؛ ترتیب دستی ذخیره می‌شود
- **تقویم فارسی (جلالی) برای انتخاب تاریخ امتحان:** یک جدول منظم و جمع‌وجور با ماه‌های فارسی، شروع هفته از شنبه، هایلایت امروز، انتخاب سریع ماه و سال و نمایش معادل میلادی هر روز
- **مباحث هر امتحان** در همان کارت امتحان: چک‌لیست مباحث با نوار آمادگی، تیک خوردن هر مبحث و جست‌وجو در آن‌ها (برخلاف زیرتسک‌ها، این چک‌لیست هر هفته صفر نمی‌شود و در خروجی ICS هم می‌رود)
- **شمارش معکوس زنده** تا امتحان: برای امتحان‌های نزدیک، ساعت و دقیقه و ثانیه‌ی باقی‌مانده لحظه‌به‌لحظه در خلاصه‌ی بالای صفحه، در نوار هشدار و روی کارت امتحان دیده می‌شود (تنها وقتی روی صفحه است، هر ثانیه به‌روز می‌شود)
- **دو زبانه: فارسی و انگلیسی** — با انتخاب زبان، جهت برنامه (راست‌به‌چپ/چپ‌به‌راست)، تقویم (جلالی/میلادی)، اعداد و نام روزها هم عوض می‌شود
- **جست‌وجوی زنده** در برنامه‌ها، توضیحات، امتحان‌ها و مباحث امتحان
- **کپی کردن برنامه** برای ساختن سریع برنامه‌های تکراری
- آرشیو خودکار آزمون‌های برگزارشده
- **پشتیبان‌گیری و بازگردانی** (JSON) + **خروجی ICS** برای گوگل‌کلندر و تقویم آیفون
- **پاک‌سازی کامل داده‌ها** با تأیید دو مرحله‌ای و امکان «برگردان»
- **میان‌برهای صفحه‌کلید:** `N` افزودن، `/` جست‌وجو، `1`/`2` جابه‌جایی تب، `Esc` بستن
- همگام‌سازی خودکار بین تب‌های باز مرورگر
- حالت روشن، تیره و هماهنگ با دستگاه (رنگ نوار مرورگر هم هماهنگ می‌شود)
- **تنظیم اندازه‌ی نوشته‌ها** از داخل تنظیمات؛ انتخاب فونت کوچک‌تر یا بزرگ‌تر با ذخیره‌ی خودکار
- ذخیره محلی و کارکرد آفلاین به‌صورت PWA
- بدون فونت، تصویر یا سرویس خارجی؛ سبک و مناسب گوشی

**سایت:** https://karoangus.github.io/Taghvim/

## دسترسی آفلاین و محدودیت دامنه

در اولین بازدیدِ کاملِ این نسخه که اینترنت در دسترس است، سرویس‌ورکر فایل‌های برنامه (HTML، همه‌ی JS/CSSهای نسخه‌دار، آیکن، manifest و صفحه‌ی جایگزین آفلاین) را با درخواست تازه در حافظه‌ی همان مرورگر ذخیره می‌کند. از تنظیمات «ذخیره آفلاین» را بزن تا کامل بودن کش و درخواستِ ماندگاری فضای ذخیره‌سازی بررسی شود؛ مرورگر ممکن است درخواست ماندگاری را نپذیرد و وضعیتش در همان کارت نشان داده می‌شود. هر نسخه‌ی تازه هم باید یک بار آنلاین باز شود تا فایل‌های به‌روزشده ذخیره شوند. بعد از آماده‌سازی، نسخه‌ی نصب‌شده از آیکنش باز می‌شود و برای دیدن یا ویرایش برنامه‌ها و امتحان‌ها به اینترنت نیاز ندارد. دکمه‌ی «تست آفلاین» صحت فایل‌های ذخیره‌شده را می‌سنجد؛ برای آزمون قطع شبکه، اینترنت را خاموش و برنامه را دوباره باز کن.

برنامه‌ها و امتحان‌ها فقط در حافظه‌ی محلی همان مرورگر و دستگاه ذخیره می‌شوند؛ پاک کردن داده‌های سایت/مرورگر یا عوض کردن دستگاه می‌تواند آن‌ها را از دسترس خارج کند. از بخش «تنظیمات ← پشتیبان و انتقال اطلاعات» مرتب فایل پشتیبان بگیر.

**محدودیت دامنه:** سایت فعلی روی GitHub Pages و دامنه‌ی `github.io` میزبانی می‌شود؛ تغییر کد به‌تنهایی آن را به دامنه یا میزبانی ایرانی تبدیل نمی‌کند و دسترس‌پذیری اولین بازدید را روی شبکه‌ی ملی تضمین نمی‌کند. برای دامنه‌ی ایرانی و میزبانی داخل ایران باید دامنه، DNS و میزبانی جداگانه تهیه و تنظیم شوند. قابلیت آفلاین فقط بعد از دریافت و ذخیره‌ی اولیه‌ی برنامه روی همان دستگاه کمک می‌کند؛ به‌تنهایی محدودیت میزبان یا شبکه را دور نمی‌زند.

## دسترس‌پذیری

- همه‌ی پنجره‌ها دیالوگ استاندارد هستند: بستن با `Esc`، حبس فوکوس داخل پنجره، بازگشت فوکوس پس از بستن و قفل اسکرول پس‌زمینه
- دکمه‌های تو در تو حذف شده‌اند؛ هر عملکرد دکمه‌ی مستقل با `aria-label` و `aria-pressed` دارد
- کشیدن و رها کردن فقط با موس و لمس است؛ جابه‌جایی با کیبورد از همان منوی ⋯ انجام می‌شود (`Esc` هم در میانه‌ی کشیدن، کارت را به جای اولش برمی‌گرداند)
- احترام کامل به `prefers-reduced-motion` و `prefers-color-scheme`

## ساختار پروژه

| مسیر | کاربرد |
|---|---|
| `app/src/main.jsx` | کامپوننت اصلی برنامه (هفته، امتحان‌ها، تنظیمات، کشیدن و رها کردن) |
| `app/src/i18n.js` | واژه‌نامه‌ی فارسی و انگلیسی + قالب‌بندی عدد و تاریخ برای هر زبان |
| `app/src/calendar.js` | تبدیل جلالی ⇄ میلادی و محاسبات تقویم (بدون وابستگی خارجی) |
| `app/src/date-picker.jsx` | تقویم جدولیِ انتخاب تاریخ امتحان (جلالی برای فارسی، میلادی برای انگلیسی) |
| `app/src/style.css` | استایل اصلی برنامه |
| `app/public/sw.js` | سرویس‌ورکر versioned، پوسته‌ی کامل و fallback آفلاین |
| `app/public/offline.html` | صفحه‌ی جایگزین برای مسیرهای ذخیره‌نشده هنگام قطع اینترنت |
| `app/public/css/offline.css`, `app/public/js/offline.js` | استایل وضعیت آفلاین و هوک‌های PWA / نصب |
| `app/public/app-version.json` | نسخه‌ی منتشرشده‌ی برنامه |
| `app/` | سورس برنامه (Vite root) |
| ریشه‌ی ریپو | خروجی بیلد که GitHub Pages از ریشه‌ی `main` منتشر می‌کند |
| `.github/workflows/deploy.yml` | به‌ازای هر push روی `main`: بیلد + تست + انتشار خودکار |
| `scripts/smoke.mjs` | تست دود: اجرای واقعی باندل تولید و بررسی رندر شدن برنامه |
| `scripts/prepare-offline.mjs` | وارد کردن فهرست فایل‌های خروجی بیلد به سرویس‌ورکر برای پیش‌ذخیره‌ی کامل |
| `scripts/offline.mjs` | آزمون کش و باز شدن پوسته‌ی برنامه و فایل‌ها در حالت بدون اینترنت |

## دستورها

```bash
npm ci        # نصب وابستگی‌ها
npm run dev   # اجرای محلی
npm test      # بیلد + تست دود (قبل از هر پول‌ریکوست)
npm run build # فقط بیلد (خروجی در ریشه‌ی ریپو)
```

هر push به `main` به‌صورت خودکار بیلد، تست و منتشر می‌شود؛ پس نسخه‌ی منتشرشده همیشه با آخرین سورس هماهنگ است.

## فرمت فایل پشتیبان

```json
{
  "app": "taghvim",
  "version": 7,
  "exportedAt": "2026-01-01T00:00:00.000Z",
  "plans": [{ "id": "…", "title": "…", "day": 0, "time": "08:30", "color": "#6558e8", "sticker": "📚", "description": "مرور فصل دوم", "order": 0, "tasks": [{ "id": "…", "title": "…", "sticker": "✏️", "done": "" }] }],
  "exams": [{ "id": "…", "name": "…", "date": "2026-01-20", "description": "مرور فصل‌های ۱ تا ۳", "topics": [{ "id": "…", "title": "فصل اول", "done": false }] }]
}
```

فیلد `order` (عدد صحیح، ترتیب برنامه درون روز خودش) اختیاری است؛ اگر نباشد، برنامه‌های آن روز بر اساس ساعت مرتب می‌شوند. فیلدهای `sticker` برای برنامه و زیرتسک اختیاری‌اند؛ اگر استیکر زیرتسک خالی باشد، شماره‌ی ایموجی آن به‌صورت خودکار نمایش داده می‌شود. فیلد `topics` (مباحث امتحان) هم اختیاری است و برخلاف زیرتسک‌ها با شروع هفته‌ی تازه صفر نمی‌شود.

هنگام بازگردانی، موارد تکراری (عنوان + روز + ساعت برای برنامه‌ها، نام + تاریخ برای امتحان‌ها) نادیده گرفته می‌شوند و داده‌های نامعتبر پاک‌سازی می‌شوند؛ پس بازگردانی هیچ‌وقت چیزی را خراب نمی‌کند.
